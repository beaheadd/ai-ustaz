# AI Ustaz

AI Ustaz — бесплатное мобильное приложение (Android и iOS), ИИ-наставник по исламу. Оно слушает, как человек читает Коран, и объясняет каждую ошибку на казахском или русском: где именно, что прозвучало, какое правило, как исправить.

Проект делается ради Аллаха и полностью финансируется из бизнеса владельца (BATR). В приложении нет платных функций, рекламы, продажи или передачи данных пользователей.

Репозиторий называется `mugalim`; «Mugalim / Мұғалім» в исследовательских заметках — это тот же проект.

## Продукты

1. **Тренер таджвида** — первый и главный.
   - Путь от алфавита к слогам, словам и сурам по методике «Муаллим сани».
   - Уроки в стиле Duolingo.
   - Голосовая проверка с тремя уровнями: «Ошибка», «Проверьте себя», тишина.
   - Точное объяснение каждого замечания.
2. **«Слушатель» для кари и учащихся хифза.**
   - Слушает чтение по памяти.
   - Находит пропущенные, лишние и заменённые слова, а также переходы в похожий аят.
   - Подсказывает, как устаз.
   - Ведёт карту слабых мест.
   - Устазу отдаёт только спорные места.
3. **Затем — модули:**
   - время намаза по ДУМК и кибла;
   - обучение намазу (ханафитский мазхаб);
   - дуа и зикр;
   - Коран с переводами на казахский и русский;
   - хадисы и тафсир — только цитаты одобренных изданий;
   - арабский для понимания;
   - семья и дети;
   - ИИ-справочник по одобренной базе — вместе с ДУМК.

AI Ustaz — помощник между занятиями с устазом. Он не заменяет учителя, не выдаёт иджазу и не выносит фетв.

## Стек (план)

- **Приложение:** React Native + Expo.
- **Сервер:** Python FastAPI и PostgreSQL на серверах в Казахстане.
- **Речевой сервис на GPU в РК:** свой сервис, модель `quran-muaalem` (лицензия QML-1.0) подключена как библиотека; `quran-transcript` и `quranic-phonemizer` (MIT).
- **Модель на телефоне** (для «Слушателя», решение после пилота): HisnLabs `tajweed-v2` (ONNX); считаем производной по QML-1.0.
- **Текст Корана:** Tanzil Uthmani v1.1 (для показа — со знаками остановки и саджды).
- **Шрифт мусхафа:** DigitalKhatt (OFL).
