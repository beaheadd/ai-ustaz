# AI Ustaz (репозиторий mugalim) — правила для агентов

## Как общаться
- Отвечать и думать ПО-РУССКИ, коротко и по делу.
- К владельцу (Эльдар) обращаться на «вы».
- Казахские тексты в интерфейсе — черновик для редактора-носителя и словаря терминов ДУМК. Не выдавать их за окончательные.

## Что это
- **AI Ustaz** — бесплатное мобильное приложение (Android и iOS), ИИ-наставник по исламу. Начинаем с правильного чтения Корана.
- Репозиторий и технические имена — `mugalim`. «Mugalim / Мұғалім» в исследованиях — тот же проект.
- Перед работой прочитать [`docs/ПЛАН.md`](docs/ПЛАН.md). По задаче также:
  - [`docs/программа-курса.md`](docs/программа-курса.md);
  - [`docs/каталог-ошибок.md`](docs/каталог-ошибок.md);
  - [`docs/слушатель-хафиза.md`](docs/слушатель-хафиза.md).
- Когда появится `docs/HANDOFF.md`, читать его перед работой и обновлять после крупного куска.

## Как запускаемся (решение владельца 18.11.2026)
- Запускаем сейчас: веб-версия на batr.kz/aiustaz, распространяем среди своих, улучшаем по ходу, выпуски часто.
- Больших денег на запуск не нужно; тяжёлые вещи (совет, тестовые наборы, команда, строгие пороги) — когда вырастем. Жёсткие правила ниже действуют с первого дня.

## Порядок продуктов (решение владельца 18.11.2026)
1. **Продукт №1 «Тренер таджвида»** — первый и самый глубокий: буквы → слоги → слова → суры по методике «Муаллим сани», голосовая проверка, точное объяснение ошибки.
2. **Продукт №2 «Слушатель»** для кари и учащихся хифза. Общее ядро с №1.
3. **Остальные модули** — время намаза, намаз, дуа, Коран, хадисы, тафсир, арабский, семья. Пока №2 не вышел, на них идёт не больше ~25% усилий; только то, что нужно №1 и №2 или каждый день ведёт в урок.

## Приложение бесплатное — ради Аллаха
- Проект полностью финансирует бизнес владельца (BATR).
- **Нельзя без явного решения владельца:**
  - платные функции, подписки, покупки в приложении, пейволы, «премиум», платные проверки устаза;
  - модули оплаты: Kaspi, Google Play Billing, IAP.
- **Никакой рекламы и рекламного трекинга:**
  - нельзя AdMob, Firebase/Google Analytics с рекламными функциями, AppsFlyer, Adjust, Meta SDK;
  - нельзя рекламный ID (`AD_ID`) и запрос ATT.

  Этого требует и лицензия QML модели `quran-muaalem`.
- Никакой продажи и передачи данных пользователей третьим лицам.
- Ограничение очереди живых устазов по ёмкости — это не платный доступ. Не превращать его в платный.

## Жёсткие правила религиозного контента
1. **Коран** выводится только дословно из проверенной базы (Tanzil Uthmani v1.1, контрольная сумма) по ссылке «сура:аят».
   - Для показа — копия Tanzil Uthmani v1.1 со знаками остановки, саджды и руб‘ аль-хизба (своя контрольная сумма). Копия из `quran-transcript` без этих знаков — только для фонетики и выравнивания.
   - Текст Корана не генерировать, не «исправлять», не нормализовать в месте хранения. Технические производные — отдельно.
   - Арабский текст, похожий на Коран, в выходе LLM блокировать.
2. **Хадисы** — только из проверенной базы: сборник, номер, степень достоверности и кто её дал. Никогда не генерировать хадисы и их оценки.
3. **Без синтеза Корана.** Коран звучит только в живых записях кари по договору. Без клонирования голосов. TTS — только для объяснений, с пометкой «синтезированный голос».
4. **Объяснения ошибок — только из утверждённой базы правил и шаблонов** ([`docs/каталог-ошибок.md`](docs/каталог-ошибок.md)).
   - Текст собирает детерминированный шаблон.
   - LLM может только перефразировать внутри базы, за флагом и через валидатор.
   - LLM никогда не получает аудио и персональные данные.
5. **Без фетв.**
   - Не говорить «ваш намаз недействителен».
   - Личные вопросы фикха — к имаму, в ДУМК или Imam AI.
   - Без ИИ-тафсира.
   - Без сектантских, политических и экстремистских тем.
6. **Линия по умолчанию** — ханафитский мазхаб и матуридитская акыда (ДУМК). Таджвид — Хафс от ‘Асыма через аш-Шатибийю. Все допустимые варианты засчитываются, политику чтения утверждает совет. Пути чтения не смешивать: настройки «Тайиба» для одной длины мадда нет; другой путь — только полным пакетом по решению совета.
7. **«Не уверен — не ругаем».**
   - На старте — только «Проверьте себя» и «Сравните». «Ошибку» включать код за кодом, когда детектор показал себя надёжно: 0 ложных на записях кари, подсказки на записях учеников подтверждает устаз. Остальное — «Проверьте себя» или тишина.
   - Плохой звук — не ошибка.
   - Не ругать за правило, которое ещё не проходили.
   - При росте — строгие пороги по коду, контексту и группе и суммарный лимит ложных «Ошибок» на 100 слов ([`docs/каталог-ошибок.md`](docs/каталог-ошибок.md) §4.1).
   - Синтез (TTS) не озвучивает ни арабские слова, ни их транслитерацию: на месте слова — клип кари или запись самого пользователя.
8. **Неверный вариант аята никогда не показывать** как текст Корана. Неправильные варианты в упражнениях — только буквы, слоги и учебные слова.
9. **Дизайн:**
   - никогда не изображать пророков и сподвижников; люди на иллюстрациях — без лиц;
   - маскот — предмет без лица или без маскота;
   - без музыки;
   - без текста Корана в уведомлениях;
   - без публичных рейтингов поклонения, жизней, сундуков, случайных наград, «хасанат-счётчиков».
10. **Не выдавать** иджазу, статус хафиза, «засчитанный хатм». «Сертификат» — только после проверки живым устазом и с пометкой «не является иджазой»; по одной проверке ИИ — только «отметка о прохождении урока» (QML 2.1(f)). Ничего не говорить о действительности намаза.
11. **Любой новый или изменённый религиозный контент** (урок, правило, шаблон, перевод, дуа, хадис, время намаза) проверяет устаз. Сейчас это знакомый устаз или кари из братьев, по ходу (решение владельца 18.11.2026: запускаемся сейчас среди своих). Пока устаз не посмотрел — на экране плашка «черновик». Публикация — с версией и хешем. Совет и ДУМК — когда вырастем.
12. **ИИ-предупреждение QML** (4 элемента, на языке интерфейса и всегда на арабском) — до первого использования и всегда доступно в меню. Тексты — [`docs/программа-курса.md`](docs/программа-курса.md), урок 0.

## Данные и приватность
- **Где хранится.** Основная БД и всё аудио граждан РК — на серверах в Казахстане. Распознавание речи — только на своих серверах в РК или на телефоне. Аудио во внешние API не отправлять.
- **Сроки хранения аудио:**
  - на сервере — удалять сразу после разбора;
  - хранить, только если пользователь сам сохранил запись или отправил её устазу (14 дней, ПЛАН §15 №7);
  - детские записи на сервере не хранятся; отправка устазу — только с согласия родителя;
  - журнал доступа к аудио — 3 года.
- **Чего не делаем с голосом:** голосовых отпечатков, входа по голосу, определения эмоций, пола и возраста.
- **Записи женщин и детей** приватны по умолчанию. Записи женщин видят только проверяющие-женщины.
- **Возраст:** v1 — для 16+ (13–17 лет — только с подтверждённым согласием законного представителя); детей до 13 в v1 не обслуживаем.
- **Обучение моделей** — только по отдельному согласию взрослого, выключенному по умолчанию. Детские записи для обучения не использовать.
- **В LLM** — только обезличенный структурированный текст: номер аята, слово, код правила.

## Готовое — сначала (указание владельца №7)

- **Лицензии:**
  - `quran-muaalem` — QML-1.0: закрепить версию и веса, не менять пакет, AI Ustaz остаётся отдельным продуктом;
  - модели Quran Lab — NPL-1.2, только по решению владельца;
  - код под GPL и AGPL не копировать;
  - данные с некоммерческими лицензиями и данные Quran Foundation для обучения не использовать.
- Каждую новую зависимость добавлять в экран «Лицензии» и `licenses/`. Каждый скопированный файл записывать в `docs/источники-кода.md`: файл → репозиторий@коммит:путь → что изменено.

## Стек и конвенции (как в BATR)
- **Стек:**
  - приложение — React Native + Expo (TypeScript);
  - сервер — Python FastAPI, PostgreSQL;
  - речевой сервис — отдельный процесс на GPU в РК.
- **Код:**
  - идентификаторы (функции, переменные) — ПО-РУССКИ; имена файлов — латиницей;
  - в шапке модуля — назначение, контракт API, решения владельца с датой; у скопированных файлов — строка «Источник: …@коммит путь».
- **Окружение и секреты:**
  - числа и строки из окружения читать только через `server/envnum.py`, не голым `int/float(os.environ...)`;
  - секреты — только в env (`/etc/mugalim.env`, права 600) или в meta через `secretbox` с маской;
  - секреты не хранить в git и не выводить в логи и ответы; keystore подписи приложения — вне git.
- **Состояние и данные:**
  - состояние между запросами — в БД, не в памяти;
  - фоновые задачи — только в `mugalim-jobs.service`;
  - модули подключаются через `register(app, …)`, зависимости — параметрами; логика — чистые функции;
  - миграции только добавляющие;
  - сутки и месяц — по Алматы (UTC+5).
- **Тесты:** на своей временной БД; прод-данные и `server/data` не трогать. Перед PR — тесты затронутой части и проверка Python (`python -m py_compile`).
- **Выкатка** (когда появится): PR → squash → GitHub Actions. В облачной сессии `deploy.sh` не запускать, ключи и SSH не просить. Прямо в main не пушить. Сливать свой PR самостоятельно — только после того, как владелец подтвердит это правило для mugalim; до этого — PR и сообщение владельцу.
- **Имена и порты:**
  - переменные `MUGALIM_*`, каталог `/opt/mugalim`, службы `mugalim*.service`;
  - API: разработка — 8030, прод — 127.0.0.1:8031;
  - свой речевой сервис — 8032: модель `quran-muaalem` подключается как библиотека, готовые процессы `engine` и `app` из пакета в проде не запускаются (они отдают только строку фонем и слушают на всех адресах);
  - лендинг (Vite) — 5373.

## Чужие зоны
- `/home/user/batr-world` и `/home/user/batr-9qum` (и `beaheadd/aialem`) — НЕ эта зона: там работают другие агенты. Не изменять их без предупреждения владельца.
- Копировать код оттуда можно, с записью источника. Импортировать их модули в рантайме — нельзя.
- Никогда не читать `/etc/world.env` и не подключаться к базе BATR. Страж в `server/boot.py` должен останавливать процесс, если он видит чужую базу.
- Из batr.kz к AI Ustaz — только ссылка. Не встраивать AI Ustaz в супер-приложение: это требование QML.
- **Временно (решение владельца 18.11.2026):** веб-прототип живёт на `batr.kz/aiustaz`, пункт «AI Ustaz» в меню batr.kz виден всем, на страницах — плашка «Прототип, черновик урока».
  - Исходники — только в `mugalim/app`. В `batr-world/web/public/aiustaz/` лежит лишь собранная статика с `version.json`; там её не править, а пересобирать отсюда.
  - Прототип не использует модель `quran-muaalem`, поэтому условия QML к нему пока не применяются.
  - До подключения модели (проверки голосом) AI Ustaz переезжает на свой домен и сервер без рекламы и платных элементов вокруг. Скрипты batr.kz (аналитика, счётчики) на страницы AI Ustaz не попадают.
