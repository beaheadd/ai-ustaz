# Лицензии AI Ustaz — сводка

Правило проекта (CLAUDE.md): каждая зависимость — на экране «Лицензии» в приложении и здесь, в `licenses/`.
Эта страница — краткая сводка. Полные тексты:

- `app-web-bundle.txt` — каждый пакет, попавший в веб-бандл, с версией и полным текстом лицензии.
  Создаёт `app/scripts/gen-licenses.mjs` (`npm run licenses` в `app/`), руками не править.
- `fonts/` — тексты лицензий своих файлов шрифтов не из npm (`Inter-OFL.txt`; источник — в первой строке «# …»).
- `data/` — атрибуция своих данных не из npm: `GeoNames-CC-BY-4.0.txt` (координаты мест для времени намаза; шапка «# …» — источник).
- `upstream/` — тексты MIT для пакетов, у которых в npm нет файла LICENSE (источник с тегом — в шапке файла):
  - `react-native-LICENSE.txt` — facebook/react-native@v0.88.1, для `@react-native/js-polyfills`, `@react-native/normalize-colors`;
  - `metro-LICENSE.txt` — facebook/metro@v0.87.1, для `metro-runtime`.
  Если в бандл попадёт пакет без текста лицензии, генератор завершится с ошибкой.

Состояние на 18.11.2026 (прототип v0, веб-сборка для batr.kz/aiustaz).

- **Без договора — не показываем.** У каждого источника `разрешено: false`; приложение не показывает ученикам ни видео,
  ни аудио такого источника (предпросмотр для владельца — отдельная сборка `EXPO_PUBLIC_MEDIA_PREVIEW=1`, не для batr.kz).
- **Включает владелец**, когда договор подписан: `content/media.json` → `источники.<id>.разрешено: true`,
  `дата_разрешения`, `условия` (кратко: что разрешено, срок, атрибуция) → `python3 -I -B tools/media/build_media.py`.
  Сюда же — строка о договоре в таблице выше.
- **Что просим в договоре:** бесплатное некоммерческое использование в AI Ustaz без рекламы и платы; файлы видео и аудио
  для своего сервера в РК; указание авторства на каждом экране (атрибуция в `media.json` показывается под каждым видео,
  «Голос: …» — под каждым клипом); право использовать записи как эталон проверки. Модель на голосе автора не обучаем
  без отдельного согласия, клонирования голоса нет.
- **YouTube не встраиваем** (реклама и метки Google — против правила «без рекламы и трекинга» и QML): пока нет своих
  файлов, урок учителя открывается ссылкой `youtube.com/watch` во внешнем приложении с пояснением
  «там может быть реклама, она не от нас». В сборке нет ни одного запроса к YouTube (CSP `frame-src 'none'`,
  `media-src 'self'`).
- Копии с сайтов загрузок (noor-book и т. п.) и перезаливы сторонних каналов не используем.

## Как обновлять

1. Новая зависимость в `app/` — только по необходимости, затем `npm run licenses` (обновит экран и `app-web-bundle.txt`).
2. Новый источник контента — запись в `content/sources.json` через `tools/build_content.py` и строка в таблице выше.
3. Скопированный чужой код — запись в `docs/источники-кода.md` (файл → репозиторий@коммит:путь → что изменено).
