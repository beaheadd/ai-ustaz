# Доступ к приложению (App access) — ответ

> Play Console → **Политика → Содержание приложения → Доступ к приложению**.

**Выбрать:** «Все функции приложения доступны без ограничений» (All functionality is available without special access).

- Входа, регистрации, пароля, подписки и кода приглашения нет.
- Все разделы открываются сразу: Главная (время намаза), Таджвид (уроки), Коран, Хадисы (раздел готовится),
  Ещё (настройки, ИИ-предупреждение, «О проекте», «Лицензии», «Установить приложение»).
- При первом запуске — короткий выбор языка и ИИ-предупреждение (на арабском и языке интерфейса); их можно пройти
  без данных о себе.
- Микрофон спрашивается только при нажатии «Записать» (разрешение сайта aiustaz.pro в Chrome). Если проверяющий
  откажет — уроки продолжаются без записи.
- Проверка голосом (кнопка «Проверить» после записи) работает, когда речевой сервис на сервере включён; если он
  недоступен, приложение честно пишет «проверка недоступна» — остальное работает.

Инструкций и тестового аккаунта для проверяющих Google не нужно.
