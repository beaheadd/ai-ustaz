# Графика для Google Play — список файлов

> Растры в git **не кладём** (CLAUDE.md, batr-world `.gitignore`). Рисует `twa/play/make-graphics.mjs` (Playwright)
> из той же эмблемы-фонаря, что значки приложения (`tools/icons/make-icons.mjs`), и из НАСТОЯЩЕЙ собранной
> веб-версии (`app/dist`). Без лиц, без текста Корана на значке и баннере, без рейтингов и наград.

Перерисовать (из корня репозитория, после `npm run build:web` в `app/`):
```
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON twa/play/make-graphics.mjs <папка>
```

скриншоты телефона 2–8 шт., стороны 320–3840 px, соотношение до 2:1 (здесь 9:16).
