# Возрастной рейтинг (анкета IARC) — готовые ответы

> Play Console → **Политика → Содержание приложения → Возрастной рейтинг** → «Начать анкету».
> Почта для связи с IARC — [контакт]. Ответы — по тому, что есть в приложении 19.11.2026.

**Категория:** «Справочные, новостные или образовательные приложения» (Reference, News, or Educational).

| Вопрос анкеты | Ответ | Почему |
|---|---|---|
| Насилие (в т. ч. мультяшное, реалистичное, кровь) | Нет | только буквы, слоги, время намаза |
| Страшный контент | Нет | |
| Сексуальный контент, нагота | Нет | люди на иллюстрациях не изображаются |
| Ненормативная лексика, грубый юмор | Нет | |
| Наркотики, алкоголь, табак | Нет | |
| Азартные игры, имитация азартных игр | Нет | наград, «сундуков» и рейтингов нет |
| Пользователи общаются или обмениваются контентом между собой? | Нет | чатов, комментариев, профилей нет |
| Приложение передаёт местоположение пользователя другим пользователям? | Нет | геолокация — только на устройстве |
| Цифровые покупки | Нет | приложение бесплатное, оплат нет |
| Неограниченный доступ в интернет (встроенный браузер на любые сайты)? | Нет | TWA открывает только aiustaz.pro; внешние ссылки открываются в браузере |
| Контент, созданный пользователями | Нет | своя запись голоса никому не показывается |
| Религиозное содержание | (отдельного вопроса нет) | учебное: чтение Корана, время намаза; без проповедей, фетв и споров |

**Ожидаемый результат:** IARC 3+ / PEGI 3 / ESRB «Everyone» (для всех).
Возрастной рейтинг — это не целевая аудитория: для кого приложение, задаётся отдельно (`target-audience.md`).
