# AI Ustaz — каркас приложения (контракт для агентов)

Expo SDK 58 (React Native 0.88, React 19.3, TypeScript 6) + веб-экспорт. Живёт на **batr.kz/aiustaz** как статические файлы. Честный прототип v0: проверки голоса ИИ нет, голоса кари нет, уроки — черновик, сервера и входа нет.

Правила проекта — `/home/user/mugalim/CLAUDE.md` (обязательны). Здесь — только то, что нужно, чтобы писать экраны.

Экран — `function Имя({ параметры }: ПропсыЭкрана<'маршрут'>)`. Заменяя заглушку, сохраните имя файла и экспорт (или поправьте `screens/index.ts`).

```ts
const { перейти, назад, заменить, наГлавную, текущий, стек, можноНазад, задатьЗащиту } = useНавигация(); // engine/navigation
перейти('урок', { номер: 3 });   перейти('оПроекте');
заменить('урок0');               // без новой записи в истории (например, онбординг → урок 0)
назад();                          // как «назад» браузера
задатьЗащиту(() => { показатьДиалог(); return true; });  // перехватить «назад» браузера/системы; null — снять
```

- **Защита ухода** (`задатьЗащиту`): пока она стоит, «назад/вперёд» браузера, свайп «назад» iOS Safari и системная «назад» Android не уводят с экрана — функция защиты вызывается, и если вернула `true`, стек остаётся, а в историю снова кладётся запись текущего экрана. Урок ставит её на время заданий и показывает «Выйти из урока?»; после подтверждения сам снимает (флаг) и вызывает `назад()`. Кнопки приложения защиту не проверяют.

- Стек живёт в состоянии; на вебе каждый шаг — запись `history.pushState` с hash и полным стеком в `history.state`. «Назад/вперёд» браузера, перезагрузка и глубокая ссылка `/aiustaz#/lesson/3` работают; внизу стека всегда главная.
- Путевой маршрутизации нет (nginx batr.kz без `$uri/`): только hash. Видимый адрес — `/aiustaz/index.html#/…` (константа `КРАСИВЫЙ_АДРЕС` в `history.web.ts` включает `/aiustaz#/…`, тогда перезагрузка идёт через редирект BATR).
- Рисуется только верхний экран: уход с экрана его размонтирует (запись голоса удаляется).
- Новый экран: маршрут в `engine/routes.ts` (`Маршруты`, `ПУТИ`, при параметрах — `ПАРАМЕТРЫ`) → файл в `screens/` → строка в `ЭКРАНЫ`. Typecheck проверит полноту.

## Хранилище и прогресс (только локально)

`engine/progress.ts`: `const { прогресс, загружен, изменить, сбросить } = useПрогресс()`.

```ts
type Прогресс = { версия: 1; язык: 'ru'|'kk'|null; предупреждениеПоказано: boolean; пояснениеМикрофонаПоказано: boolean;
  уроки: Record<string, { пройден; лучший /*0..1*/; попыток; последний /*ГГГГ-ММ-ДД*/ }>; дниЗанятий: string[] };
изменить(п => отметитьУрок(п, 3, { доля: 0.9, пройден: true }));   // сохраняет сам, отмечает день занятий
изменить(п => ({ ...п, предупреждениеПоказано: true }));
днейЗанятийЗа(прогресс, 30);   датаАлматы();                       // сутки по Алматы (UTC+5)
```

Место в незаконченном уроке — `engine/lessonSession.ts`: `sessionStorage` `aiustaz:прохождение` (номер и версия урока, номер задания, итоги заданий; живёт до закрытия вкладки; без аудио). На вступлении урока — «Продолжить с задания K» / «Начать заново»; итог урока и «Выйти» его забывают.

Ключ в `localStorage`/AsyncStorage — `aiustaz:progress.v1` (`engine/storage.ts`: `прочитатьJSON`, `записатьJSON`, `удалитьКлюч`, префикс `aiustaz:`). Только номера уроков, результаты, даты и настройки. Никаких персональных данных и аудио. Без серий «сгорает», очков и рейтингов — «N из последних 30 дней».

## Запись голоса

- Проще всего — `<ПанельЗаписи />`. Ниже уровнем — хук `useЗаписьГолоса({ максДлительностьМс })` → `{ снимок: { состояние, ошибка, длительностьМс, естьЗапись }, уровень /*0..1*/, поддерживается, начать, остановить, воспроизвести, остановитьВоспроизведение, удалить }`.
- `состояние`: `ожидание | запрос | запись | записано | воспроизведение`; `ошибка`: `нет-доступа | нет-микрофона | не-поддерживается | небезопасно | занят | неизвестно`.
- Веб: MediaRecorder + AnalyserNode. Запись — Blob в памяти страницы, **никуда не отправляется**; микрофон освобождается сразу после «Стоп»; скрытие вкладки/уход останавливают запись; размонтирование стирает запись. Нативно — заглушка (TODO: expo-audio).
- Перед первым запросом микрофона — `ПояснениеМикрофона` (флаг `пояснениеМикрофонаПоказано`).
- **Вердикта по голосу нет**: только «Записали! Послушайте себя». Никаких «Верно/Ошибка» по записи.

## Контент (`src/content/types.ts`, данные — `/content/*.json`)

- `Урок { номер, id, уровень, название, цель, новое, задания: Задание[], критерий: { доляВерных: 0.8 }, версия, статус, утверждено, примечание? }`.
- `Задание` (у всех есть `id`, например `'L03-07'`):
  - `теория` — карточка (`заголовок`, `текст`, `примеры?`, `буква?`);
  - `знакомство` — буква: `знак`, `название`, `формы` (с татвилем ـ; у хамзы `null`), `соединяетсяСлева`, `подсказка` (каталог §8 или `null`), `подмены[]`, `примеры`. Не оценивается;
  - `выбор` — тап, один верный; `вид?`: `буква | слог | огласовка | собери | пара | форма | вСлове | соединение` (только оформление); варианты — буквы/слоги/учебные слова или текст; `пояснение?` после ответа. **Две попытки, в долю урока идёт первая** (`components/exercises/useChoice.ts`): первая ошибка — «Посмотрите ещё раз», верный не раскрывается, «Далее» закрыто; верный ответ или вторая ошибка — задание завершено, верный подсвечен, «Далее» открыто. Арабские варианты в обратной связи — карточками «Ваш выбор» / «Нужно» крупным шрифтом;
  - `прочитай` — `строки: [{ арабский, транскрипция }]` строкой справа налево с переносом; транскрипция под каждым слогом, скрыта и открывается по нажатию. Задание готово сразу, нижняя кнопка — «Прочитал(а) — дальше». Не оценивается;
  - `запись` — читать учебный текст (`читать.учебный`) или `ФрагментКорана`, без вердикта;
  - `лестница` — ступени слог → слово, каждую записать себя; пока ступень не последняя, нижняя кнопка — «Следующая ступень».
- **Контракт упражнения** (`components/exercises/common.tsx`): `{ задание, приГотово(итог, { сразуДалее? }), заменитьДалее?(замена | null) }`. `заменитьДалее({ надпись, приНажатии?, testID? })` меняет нижнюю кнопку экрана урока (только надпись — кнопка по-прежнему ведёт дальше; с `приНажатии` — своё действие); сбрасывается при переходе к следующему заданию. Обратная связь (`ОбратнаяСвязь`) сама прокручивает экран к себе.
- Урок пройден: доля верных в `выбор` ≥ `критерий.доляВерных` (0,8). `теория`, `знакомство`, `прочитай`, `запись`, `лестница` в долю не входят.
- `ФрагментКорана { сура, аят, текст, слова?, источник: 'tanzil-uthmani-1.1', файл? /*имя XML Tanzil*/, хеш /*sha256*/ }` — текст только программно из Tanzil Uthmani v1.1, дословно. Неверный вариант аята не показывать никогда.
- `ГолосКари` в прототипе всегда `null` («голос кари появится после записи эталона»). Синтез арабских звуков запрещён.
- `ЛокализованныйТекст = { ru, kk }`; `СтатусКонтента = 'черновик' | 'проверен-устазом' | 'подписан-советом'`.
- Файлы `/content`: `course.json` (`КартаКурсаДанные`: уровни 0–4 → пункты с `метка`, `вид`, `очередь`, `доступен`, `файл`), `lesson0.json` (`Урок0Данные`: `предупреждениеИИ` ar/ru/kk, `маршрут`, `намерение` — не сохранять, `задания`), `lessons/level1/L01…L16.json`, `K1.json` (`Урок`), `letters.json` (`БукваДанные[]`), `harakat.json` (`ЗнакДанные[]`), `fatiha-demo.json` (`ДемоФатихи`: аяты 1:1–7 из Tanzil + 7 примеров объяснений, слово — по номеру с 1), `sources.json`, `version.json`.
- Номера в маршруте `#/lesson/N`: 1–16 — уроки, **К1 = 101** (К2 = 102, К3 = 103, Итог = 104, Н1–Н4 = 111–114 — пока недоступны). Урок 0 — свой экран `урок0`.
- **Загрузка — лениво, отдельными чанками с хэшем.** Реестр `src/content/registry.ts` — фасад: `загрузитьКурс()`, `пунктКурса(курс, номер)`, `естьУрок(номер)`, `загрузитьУрок(номер)` (1–16, 101), `загрузитьУрок0()`, `загрузитьДемоФатихи()`, `загрузитьБуквы()`, `загрузитьЗнаки()`. Реализация одна: уроки — `engine/lessonEngine.ts` (`require.context` по `/content/lessons`, проверка формы и sha256 аятов), остальные файлы — `components/info/data.ts` (`useДанные`, `загрузитьДанные`). Статический `import` JSON из `/content` в экраны не делать: данные раздувают основной бандл (урок — 7–15 КБ, gzip 2–3 КБ). Временных фикстур уроков больше нет (`screens/__fixtures__` удалена 18.11.2026).
- Данные собирает `python3 -I -B tools/build_content.py` (из docs/ и Tanzil; руками JSON не править — правки в генератор и пересборка), проверяет `python3 -I -B tools/check_content.py` (Коран побайтно с Tanzil и файл фрагмента = файл в sources.json, id, ru+kk, учебные слоги — на уровне 1 без мадда (`ِيْ`, `ُوْ`, `َا`…), задания, казахские названия букв = глоссарий). `-B` — чтобы не оставлять `__pycache__`. Поправки к подсказкам каталога §8 (ب, د, غ) — `ПОПРАВКИ_ПОДСКАЗОК` в генераторе, до переноса в каталог. Путь к XML Tanzil: `--tanzil ПУТЬ` или `MUGALIM_TANZIL_XML`.

## Сборка и проверка (из `app/`)

```
npm install
npm run typecheck      # tsc --noEmit — без ошибок

npm run test:e2e       # сквозной тест: телефон (iPhone 13) и десктоп 1280×800 — онбординг, урок 0, урок 1 целиком, карта,
                       # «Как объясняем», язык, отказ микрофона; урок 2 — две попытки, обратная связь над панелью,
                       # «назад» посреди урока, продолжение после перезагрузки; плюс все уроки на 360 px. SCREENSHOTS=папка — снимки
npm run serve:test     # http://127.0.0.1:5390/aiustaz — как на batr.kz (заглушка BATR с редиректом)
npm run licenses       # после смены зависимостей: src/legal/licenses.json + /licenses/app-web-bundle.txt
npm run web            # дев-сервер Expo (http://localhost:8081/aiustaz)
```

`npx expo install <пакет>` — для пакетов SDK (при закрытом api.expo.dev: `EXPO_OFFLINE=1 npx expo install …`). Выкладка: содержимое `app/dist/` → `batr-world/web/public/aiustaz/` (делает ведущий; nginx batr не меняем; `/aiustaz` без файла → index.html BATR → скрипт-редирект на `/aiustaz/index.html` **с тем же `location.search + location.hash`**).

`check-dist` требует: в index.html нет неподставленных меток `%…%`, есть `<html lang>` и `<title>`, `<meta charset>` — в первых 1024 байтах; ни одного растрового файла; хэш в имени у всех файлов, кроме `index.html`/`metadata.json` (SW batr кэширует по URL навсегда); пути в index.html от `/aiustaz/`; CSP в index.html; нет внешних URL кроме разрешённого списка с причинами; ни один путь не попадает под `.gitignore` batr-world (`git check-ignore`, только чтение); бюджет размера (JS ≤ 1200 КБ, всё ≤ 3000 КБ).

## Правила (коротко)

- **Никаких растровых файлов** (png/jpg/jpeg/webp/gif/ico/bmp): иконки — SVG, текст, эмодзи без лиц. Ассеты из `node_modules` попадают в `dist/assets/<имя>.<md5>.<расш>` плоско (плагин `scripts/metro-asset-paths.js`: `.gitignore` batr-world режет каталоги `node_modules/`, `dist/`, `data/`…).
- **Никаких внешних запросов**: шрифты, данные, библиотеки — только в бандле. CSP в dist/index.html запрещает остальное. Без аналитики, трекеров, рекламы, Sentry, входа, сервера.
- Новая зависимость — только по необходимости, `npx expo install`, затем `npm run licenses`.
- Плашка «Прототип. Черновик урока — проходит проверку устаза» — на каждом экране урока.
- Дизайн: спокойно, без музыки, без лиц, без маскота, без жизней/сундуков/случайных наград/рейтингов/хасанат-счётчиков. Телефон 360–430 px и десктоп (колонка ~480 px).
- Тяжёлые данные (длинные тексты) — через `import()`: Metro выносит их в отдельный чанк с хэшем (пример — экран «Лицензии»).
- Минификатор пишет не-ASCII как UTF-8, а не `\uXXXX` (`metro.config.js`, `ascii_only: false`): JS сборки 875 КБ вместо 1415 КБ. Кодировка чанков — по `<meta charset="utf-8">` страницы (в первых 1024 байтах `public/index.html` — описание шаблона стоит ПОСЛЕ неё; проверяет check-dist). В комментариях шаблона не писать метки `%LANG_ISO_CODE%`/`%WEB_TITLE%`: Expo заменяет только первое вхождение.
- До загрузки JS в `#root` стоит строка «AI Ustaz загружается… / жүктелуде…» (react-native-web заменяет её при монтировании).
- Текст интерфейса со вставками арабского (названия уроков, вопросы, теория, пояснения) — через `СмешанныйТекст` (`components/info/MixedText.tsx`): арабские куски — Amiri Quran и изоляция направления (`ا/ء` не переворачивается).
- `docs/`, `CLAUDE.md`, `README.md` не трогать без задания. Не коммитить и не пушить — это делает ведущий.
