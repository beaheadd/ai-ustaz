# Речевой сервис AI Ustaz

Проверка чтения на готовой модели `quran-muaalem` 0.3.0 (лицензия QML-1.0). Модель подключена как библиотека: пакет и веса не меняем, версия весов закреплена — `obadx/muaalem-model-v3_2@01a1ef9`.

Сервис отдаёт:
- распознанные фонемы с уверенностью;
- расхождения с эталоном с кодами каталога ошибок.

Текст объяснения собирает клиент по шаблонам каталога (CLAUDE.md, правило 4).

## API (127.0.0.1:8032, снаружи — `/api/speech/` своего домена)
- `GET /v1/zdorovye` — состояние сервиса.
- `POST /v1/proverka` — multipart:
  - `audio` — WAV 16 кГц моно, до 20 с;
  - эталон: `text` (учебный слог или слово) **или** `sura` + `aya` (+ `word_from`, `words`);
  - `kinds` — необязательно, какие виды правил урок уже прошёл.

  Ответ:
  ```
  {статус, эталон:{текст, фонемы}, услышано:{фонемы, уверенность_ср}, замечания:[…], время_мс}
  ```
  Каждое замечание:
  ```
  {код, вид, уровень, позиция, фрагмент, ожидалось, услышано, счёт_ожидался, счёт_услышан, правила, уверенность}
  ```

## Правила
- **Уровни.** На старте только «проверьте» и «подсказка». «Ошибку» сервис пока не выдаёт (CLAUDE.md, правило 7).
- **Уверенность.** Сервис сравнивает две гипотезы — «как услышано» и «как в эталоне» — по CTC той же записи. Если перевес ниже `MUGALIM_SPEECH_MIN_LLR` (по умолчанию 2), он молчит.
- **Допустимые варианты не замечаются:**
  - ‘арид и лин — 2, 4 или 6;
  - муттасиль — 4–6;
  - мунфасиль — 4–5;
  - мунфасиль на 2 — мягкая подсказка без штрафа.
- **Плохой звук** (тихо, перегруз, коротко) — не ошибка: замечаний нет.
- **Приватность.** Запись только в памяти, на диск и в журнал не попадает, удаляется сразу после разбора.

## Запуск локально
```
cd speech && python3 -m venv .venv && . .venv/bin/activate
pip install --index-url https://download.pytorch.org/whl/cpu torch==2.15.0 && pip install -r requirements.txt
MUGALIM_SPEECH_MODEL_DIR=<папка весов> uvicorn aiustaz_speech.app:app --host 127.0.0.1 --port 8032
python -m pytest tests -q                  # без модели; с MUGALIM_SPEECH_MODEL_DIR — и с ней
MUGALIM_SPEECH_MODEL_DIR=… python -I tools/eval_qdat.py   # замер на открытом наборе qdat_bench
```

## Сервер (сейчас — сервер BATR, решение владельца 19.11.2026)
- `sudo bash speech/deploy/setup-speech.sh` — пользователь `mugalim`, `/opt/mugalim`, служба `mugalim-speech`.
- Потолок нагрузки: 2 ядра, 4 ГБ памяти, низкий приоритет, одна запись за раз — чтобы не мешать batr.kz.
- `speech/deploy/nginx-aiustaz.conf` — сайт своего домена.

  Проверку голосом включаем только на своём домене, не на batr.kz: этого требует QML.
