- **Время намаза** — свой расчёт на телефоне методом ДУМК (ISNA 15°/15°, аср ханафи, поправки ±3/±5, UTC+5), подпись «Расчёт по методу ДУМК (±1 мин)», не «по данным ДУМК»; таблиц ДУМК в сборке нет. Кызылорда сверена повторно — ≤ 1 мин (прежние 3 мин — сбой API), оговорки нет. **Вопрос владельцу:** 6 точек из списка мест ДУМК (Алатау, Қаскелең, Жем, Қордай, Байқоңыр, Казталов) оставить или заменить на GeoNames с оговоркой до ±4 мин (исследование 13, «Обновление»).

- **Не сделано (на потом):** ленивая загрузка экранов (≈ 240 КБ основного чанка, нужен экран «нет связи» для чанка), Amiri в woff2, gzip на batr.kz — проверить `curl -sI -H 'Accept-Encoding: gzip' …/index-*.js` (зона batr-world, только владелец).

## Как устроено
- **Исходники приложения** — `app/` (Expo SDK 58, TypeScript, экспорт для веба). Контракт — `app/ARCHITECTURE.md`.
- **Данные уроков** — `content/`. Их собирает `tools/build_content.py` и проверяет `tools/check_content.py` (сверка с Tanzil, мадд на уровне 1, глоссарий kk).
- **На batr.kz лежит только собранная статика** — `batr-world/web/public/aiustaz/`, версия в `version.json`. Там её не править.
- **Адрес /aiustaz** отдаёт index.html сайта BATR. Его первый скрипт перенаправляет на `/aiustaz/index.html`, потому что nginx batr.kz не настроен на отдачу папок (нет `$uri/`).
- **Навигация внутри** — через hash (`#/lesson/3`).

## Как выпустить новую версию
1. Править в `app/` и `content/`, затем `npm run typecheck`, `python3 -I tools/check_content.py`, коммит.
2. Запустить `bash tools/release-batr.sh`. Он собирает, прогоняет e2e и пушит ветку `claude/aiustaz-<коммит>` в batr-world.
3. Создать PR в batr-world main и сделать squash-слияние (по правилам batr-world агент сливает свой PR сам), затем дождаться job «Выкатка на сервер» в Actions.
4. batr.kz из облачной сессии недоступен (прокси) — проверять по логу Actions: в поле `version` должен стоять новый коммит.

## Открытые замечания
- **Копия Tanzil для показа.** Нужна копия со знаками вакфа, саджды и хизба. Сейчас аль-Фатиха показывается из фонетической копии; для 1:1–7 разницы нет, перед показом других сур нужна копия со знаками (sources.json).
- **Каталог ошибок.** В `docs/каталог-ошибок.md` §8 и §10.1/§13 нужно перенести правки подсказок, сделанные в генераторе:
  - غ — «из верхней части горла, ближе ко рту»;
  - ب/د — раздельные подсказки;
  - ح — «х̣а» в шаблоне.
- **Лишние загрузки.** На голом адресе /aiustaz браузер успевает предзагрузить 3 файла BATR, но не выполняет их. Это уйдёт с переездом на свой домен.
- **gzip в nginx batr.kz не проверен.** JS весит 891 КБ, после gzip — около 235 КБ.
