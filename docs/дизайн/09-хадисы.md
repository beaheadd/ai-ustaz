# 09. Хадисы аль-Бухари (HadeethEnc.com)

**Запрос владельца (21.11.2026):** «Добавь хадисы Аль-Бухари ещё перевод!»

**Решение ведущего 21.11.2026:** хадисы «Сахиха» аль-Бухари с переводом из HadeethEnc.com — дословно и целиком, со
ссылкой на страницу каждого хадиса; акыда и ряд тем — только после одобрения устазом; всё остальное — с плашкой
«Черновик — проверяет устаз». Исследование и условия — [14 §3.9](../исследование/14-коран-тафсир-хадисы-аудио.md).
Код: `tools/hadith/` (сборка и проверка), `app/src/hadith/` (загрузка), `app/src/screens/Hadith*.tsx`.

## 1. Условия HadeethEnc и как мы их соблюдаем

Условия (описание официальной коллекции API, проверено 21.11.2026): «Contents of the project can be used, with the
following terms and conditions: 1. No modification, addition, or deletion of the content. 2. Clearly referring to the
publisher and the source (HadeethEnc.com).»

| Условие | Как соблюдаем |
|---|---|
| Без изменений | Строки из выгрузки не меняются, не нормализуются; `check_hadith.py` сверяет КАЖДОЕ поле посимвольно с SQLite (и SQLite — с CSV той же версии); e2e — текст на экране побайтно = файлу |
| Без удалений | Хадис показывается целиком: заголовок, арабский текст, перевод, степень, кто передал, разъяснение, польза, значения слов (ar), ссылки (ar). Разъяснение свёрнуто, по нажатию — весь текст. Обрезка заголовка в списке — только глазами (2 строки), целиком — на экране хадиса |
| Без добавлений | Наши подписи («Степень:», «По данным HadeethEnc.com», плашка) — отдельные строки интерфейса, в текст хадиса не вставляются |
| Ссылка на источник | У каждого хадиса — «Источник: HadeethEnc.com» → его страница (`link` из CSV языка перевода); в разделе — строка источника; на «Лицензиях» — условия дословно |

Узбекский перевод HadeethEnc — **кириллицей**; интерфейс uz — латиница. Не транслитерируем (это изменение текста),
показываем как есть с пометкой «… kirill yozuvida, manbadagidek».

## 2. Что показываем, что нет

- **Отбор** — по полю `attribution` арабской выгрузки (такхридж): аль-Бухари передал сам хадис («رواه/أخرجه البخاري»,
  «متفق عليه», «صحيحيهما»). Исключены 25 из 1807 упоминаний: муаллякат (6), «аль-Адаб аль-Муфрад» (3), другие книги
  аль-Бухари (3), «асль» — у аль-Бухари только основа (4), асары (3), аль-Бухари лишь частично после другого сборника (6).
- **Только с русским переводом** — 1155 из 1782; 627 без перевода ru пока не показываем (kk читает русский).
- **Ждут устаза (не публикуются)** — 342: акыда (правило 6: линия ДУМК — матуридитская акыда, разъяснения HadeethEnc
  готовили в Эр-Рияде) — 228; джихад — 40, худуд — 24, шариатская политика — 28 (правило 5); цитата Корана в арабском
  тексте — 50 (правило 1: Коран — только из Tanzil; сверку и способ показа решает устаз, 14 §3.6). Список с причинами и
  ссылками — `content/hadith/на-проверку-устаза.json` (пишет сборка).
- **Показано** — 813 хадисов: ru — все, en — 813, uz — 130.
- **Одобрение:** `content/hadith/одобрено.json` — `"<id>": {"кто": "…", "когда": "ГГГГ-ММ-ДД"}` и пересборка. Одобренный
  показывается без плашки («Проверил устаз: …»), одобренный из «ждут устаза» — появляется. Текст устаз не правит.

## 3. Экраны

| Экран | Адрес | Что на нём |
|---|---|---|
| «Хадисы» (раздел меню) | `#/hadith` | «Сахих аль-Бухари», откуда и что дословно, плашка «Черновик»; «ИИ хадисы не пишет, не переводит и не пересказывает» + «уточните источник у имама»; поиск (номер по порядку, номер HadeethEnc, слова заголовка); 6 разделов HadeethEnc с числом хадисов; строка «что ждёт устаза»; источник; «Лицензии»; «Продолжить обучение» |
| Раздел | `#/hadith/list?n=<id>` | Путь раздела, подразделы с числом хадисов, хадисы раздела: номер, заголовок (2 строки), «аль-Бухари · степень» |
| Хадис | `#/hadith/item?n=<id>` | «Хадис № n», «HadeethEnc № id», плашка; заголовок → арабский текст (системный арабский шрифт, не Amiri Quran: это не Коран; `lang="ar" dir="rtl"`) → перевод → «Степень: … · По данным HadeethEnc.com» → кто передал → «Разъяснение», «Польза хадиса», «Значения слов (ar)», «Ссылки на источники (ar)» (раскрываются) → «Личные вопросы фикха — к имаму или в ДУМК» → «Источник: HadeethEnc.com» (новая вкладка) → разделы хадиса |

- **Язык перевода:** ru → ru; en/uz → свой, если есть, иначе русский со строкой «перевода пока нет — русский»; kk →
  русский и «Қазақ тіліндегі аударма әзірге жоқ — орысша аудармасы» (черновик для редактора-носителя).
- **Арабский текст:** если перевод сделан по прежней редакции арабского текста (у HadeethEnc `ar_version` ≠ `version`,
  ru — 13 хадисов), показываем арабский текст ИЗ выгрузки перевода (`hadeeth_ar`), чтобы текст и перевод совпадали.
- **Данные** — статические файлы `app/public/hadith` (≈ 7,5 МБ): индекс (≈ 155 КБ), заголовки языка (ru ≈ 270 КБ),
  порции по 50 хадисов на язык; грузятся fetch'ем со сверкой sha256 (манифест в бандле → индекс → файл). Текста
  хадисов в JS нет (`check-dist` п. 12). Ссылки на hadeethenc.com — только переход по нажатию, запросов нет (CSP).
- **Нет:** уведомлений с хадисами, ИИ, генерации, машинного перевода, оценок «нашими словами».

## 4. Что ждёт устаза и владельца

1. **Устаз:** 342 хадиса из `на-проверку-устаза.json` (акыда — 228); 813 показанных — плашка «Черновик» до просмотра.
   Особенно: разъяснения по фикху (ханафитский мазхаб vs позиция разъяснения), ссылки на Ибн База, Ибн Усаймина и др.
   в поле `reference` (показываем как есть — убрать нельзя по условиям HadeethEnc).
2. **Владелец:** согласие ДУМК на HadeethEnc (в 14 §5 вопрос 19 было «только после согласия ДУМК») — сейчас запускаемся
   среди своих с плашкой «черновик»; публичный выпуск — после ответа ДУМК.
3. **Владелец:** 627 хадисов без русского перевода (только арабский, частично en) — показывать ли с арабским текстом и
   английским переводом?
4. **Редактор-носитель:** подписи kk, uz, en.
